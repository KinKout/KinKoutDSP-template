# assets folder
___
#### [This folder][link_assets] is a place to save all the raw binary data needed by the plugin.
___

It is divided into 4 categories:

- audio: .wav, .aiff
- data: .svg, .json, .xml - *(presets, lookup tables, coefficients etc.)*
- fonts: .ttf, .otf - *(custom fonts used in the plugin UI)*
- images: .png, .jpg - *(backgrounds, knobs, sliders, VU meters and other UI graphics)*




[link_assets]: https://github.com/KinKout/KinKoutDSP-template/tree/main/assets
